# Raven Colonial API

The live community standard for tracking colonisation build projects. This is the tool that filled the gap after EDDB shut down, and it's the only working colonisation API found in a 2026 survey.

Web UI: https://ravencolonial.com

## Resolve the host at runtime

The docs domain redirects (301) to an autogenerated Azure hostname:

```
https://ravencolonial.space
  -> https://ravencolonial100-awcbdvabgze4c5cq.canadacentral-01.azurewebsites.net
```

**Do not hardcode the Azure hostname.** It's a default App Service domain, which means it can change whenever the deployment does. Follow the redirect from `ravencolonial.space` instead:

```bash
HOST=$(curl -s -o /dev/null -w '%{redirect_url}' https://ravencolonial.space | sed 's#/$##')
curl -s "$HOST/api/system/Sol"
```

No API key for reads.

## Endpoints

```bash
curl -s "$HOST/api/system/Sol"       # v1
curl -s "$HOST/api/v2/system/Sol"    # v2 also live
```

```json
[{"buildId": "3684c1a4-46b2-467f-9a1e-0eee8c876056",
  "buildType": "prometheus", "buildName": "My Template",
  "marketId": 123456, "systemAddress": 10477373803,
  "systemName": "Sol", "starPos": [0, 0, 0],
  "architectName": "Cloudas", "maxNeed": 21620,
  "complete": false, "timeDue": null, "isPrimaryPort": false,
  "reserveLevel": "common", "bodyNum": null,
  "factionName": null, "discordLink": null}]
```

`/api/project/` returns HTTP 405 — it exists but needs POST/PUT. There is no Swagger endpoint (`/swagger/*` is 404).

Both v1 and v2 respond; prefer v2 for new work and fall back to v1 if a field you need is missing.

## Expect the schema to move

This is a young, fast-moving project — the web frontend was pushed 2026-07-24 and its sibling tool SrvSurvey 2026-07-31. Write defensively: treat unknown fields as additive, don't assume field presence, and re-check the shape if something breaks rather than assuming the service is down.

## Verify the content type

Like DCoH, this is an SPA that can return HTTP 200 with an HTML shell for unmatched paths. Assert the response is `application/json` before parsing — a status-code check alone will silently hand you a web page.

```bash
curl -s -o /dev/null -w "%{http_code} %{content_type}\n" "$HOST/api/system/Sol"
```

## Colonisation context worth knowing

Two patch-note details shape what's worth building where:

**Bodies with organics boost several economies.** Since Trailblazers Update 3 (v4.1.2.0, 30 Apr 2025), a build on or orbiting a body with organics boosts Agriculture, High Tech, and Tourism economies, and triggers Agriculture/Terraforming colony overrides. Overrides stack — a high-metal-content world with organics gets Extraction *plus* Agriculture and Terraforming. So exobiology scouting and colonisation site selection genuinely overlap.

**Vista Genomics has activation requirements** (Trailblazers Update 3.3, 5 Jun 2025). To get one in a colonised system you need either a Tier 3 port, or a Tier 1/Tier 2 port plus one of: a strong link to a Satellite Installation, Comms Installation or Relay Station; or a Medical Installation or Scientific Hub in-system. Worth knowing if the user wants somewhere local to sell biodata.
