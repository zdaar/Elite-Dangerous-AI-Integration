# Exobiology species values — verified 2026-08-04

118 Vista Genomics species across 22 genera, plus 4 Thargoid xeno samples.

**First Logged = 5× base.** The bonus *added* is 4× base, so total paid is 5× base. Both the "4x" and "5x" figures in circulation describe this same payout. Set by Update 14 (2022-11-29) and unchanged since — no exobiology payout rebalance has occurred through August 2026.

**Distance** is the genus Clonal Colony Range: the minimum separation between the three samples. It is set per *genus*, never per species.

All organisms need **3 samples** except those marked ①, which need only one.

## Data provenance and known-bad sources

Primary: [Canonn Vista Genomics Price List](https://canonn.science/codex/vista-genomics-price-list/) — built from uploaded commander sale data, actively maintained. Cross-checked against [EDMC-BioScan rulesets](https://github.com/Silarn/EDMC-BioScan/tree/master/src/bio_scan/bio_data/rulesets) (repo last commit 2026-07-11), [EDMC-ExploData genus.py](https://github.com/Silarn/EDMC-ExploData/blob/master/src/ExploData/explo_data/bio_data/genus.py) for distances, Fandom per-genus pages, and [ed-dsn.net](https://ed-dsn.net/en/vista-genomics-values/).

Two sources are wrong in specific, identifiable ways — worth knowing so you don't "correct" this table against them:

**Fandom's "Exobiology Sample Values and Details" summary page** was created in a single paste on 2024-07-30 and never value-corrected. It is the sole outlier on eight entries, and Fandom's own per-genus pages contradict it. Rejected: Bacterium Nebulus 9,116,600; Bacterium Scopulum 8,633,800; Amphora Plant and Crystalline Shard 3,626,400; Brain Trees 3,565,100; Anemone Croceum 3,399,800; Sinuous Tuber Albidum 3,425,600; Tussock Ventusa 3,277,700 (digit transposition of 3,227,700).

**EDMC-BioScan carries `16777215` for Concha Biconcavis.** That is 0xFFFFFF — a placeholder sentinel, not a price. Canonn, ed-dsn and Fandom's Concha page all say 19,010,800. BioScan is correct on Fonticulua Fluctus (20,000,000), so the error is specific to Biconcavis.

Also note elitedangerous.net prints Bacterium Cerbrus 5× as 8,499,000; the correct arithmetic is 8,449,000.
